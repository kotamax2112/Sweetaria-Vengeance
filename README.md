🎮 Sweetaria: Vengeance

A fast-paced SNES-style runner with bosses, powerups, RPG mechanics, and full customization.

Built entirely with HTML5 Canvas, CSS, and JavaScript by Dakota Weatherhead.


---

⭐ Overview

Sweetaria: Vengeance is an arcade-fast side-scrolling action game where you dodge hazards, unlock cosmetic skins, collect powerups, and battle through two unique boss encounters — including a full RPG-style final fight.

This repository contains the Full Stable Build 1.0, serving as the foundation for future Alpha versions.


---

🚀 Features

10-level Story Mode

Two Boss Battles

Wardrobe System: name, gender, hairstyle, skin tone, shirt color, pants, held items

Unlockable Skins

Achievements System

Clues & Lore Menu

Checkpoint & Death Menu

Powerups: Jetpack, Laser, Shield

Dev Menu (hidden)

Local Save Data (progress stored in browser)

🧑‍💻 Running the Game

Local (easy)

Just open index.html in any browser.

GitHub Pages (recommended)

1. Go to Settings → Pages


2. Set “Source” to Deploy from Branch


3. Select the main branch


4. Save


5. Your playable link becomes:



https://<your-name>.github.io/Sweetaria-Vengeance/
